# Adoption reviewer — minimizing the old Notion/Calendar failure pattern

Outcome: keep HQ on the phone, not another place to maintain projects.

Observations from the user's established workflow: the user already does substantial research, document review, immigration paperwork, and decisions through ChatGPT. Past task systems failed when they required manual bookkeeping or generated too many calendar tasks without useful notifications. Therefore, the new flow should be:

1. Do the actual work with ChatGPT.
2. ChatGPT records an evidence-backed outcome, next action, and deadline into the private HQ Google Sheet.
3. The free bridge brings that record to the phone in the next scheduled pass.
4. HQ's Today view chooses a single high-leverage next action; the refocus action opens a prepared ChatGPT handoff, never an unrelated AI.
5. Opt-in email alerts include at most three actions twice per day; no excessive calendar events, no routine notifications for every change.

Failure trigger: if the user has to repeatedly copy chat summaries, maintain a manual dashboard, or receive more reminders than actionable decisions, stop adding features and fix that workflow.
