Adarsh HQ: Turn on free background sync

One ChatGPT assistant. Your private Google Sheet remains the shared work record. Firebase stays on Spark. This helper installs a scheduled Google Apps Script bridge—no second AI and no paid Firebase Functions.

Important: This is a setup helper, not a one-click remote deployment. You must approve the Google authorization yourself. Do not paste private UID, passwords, or tokens into ChatGPT or GitHub. Don't enable Blaze or billing.

1. Open your existing private HQ Sheet

In your Google account, open the private HQ spreadsheet, choose Extensions → Apps Script. On Android Chrome you may need Desktop site.

Add a NEW code file named HQ_FreeBridge. Do not delete or replace existing script files.

2. Set the Google Cloud project and scopes

In Apps Script Project Settings, associate it with your existing Firebase standard Google Cloud project (project number 660024483095). This does not require enabling billing. Check the authorization prompts carefully.

Enable the appsscript.json manifest editor. Merge these OAuth scopes into any existing manifest; don't remove older scopes or settings if your Sheet already uses other scripts.

3. Enter your private Firebase UID

Firebase Console → Authentication → Users. Copy your signed-in user's UID. In Apps Script → Project Settings → Script properties, add FIREBASE_UID = that UID.

No email reminders: keep HQ_EMAIL_REMINDERS=false. Your free 15-minute sync does not require emails. Android push is an optional separate pilot, OFF until you choose to test it.

4. Test before scheduling

  1. Select hqCheckConnection and click Run. Authorize the displayed permissions.
  2. When it returns ok: true, run hqTick ONCE. Verify that your phone still shows all projects and the new private sync timestamp.
  3. Only then run hqInstallFreeTriggers to install one scheduled 15-minute check.
  4. To stop it later, run hqRemoveFreeTriggers. You can inspect real failures under Apps Script → Executions.

5. Test actual round-trip

Make a harmless test task on the phone. After a successful hqTick, verify that it reaches HQ Jobs in the private Sheet. Then have ChatGPT update a verified test record there, run the script again, and confirm the phone reflects it. The app does not start a ChatGPT turn automatically.

The code uses an owner-approved Apps Script OAuth token scoped for your existing Google Cloud project. It is never saved to this site. Google service quotas, IAM, and OAuth setup can affect activation.
